# Analysis Flow

`00–03` **Data foundation**  
Import verification → database → schema → import mapping/reference.

`04–05` **BTTS evaluation**  
Classification accuracy → probability calibration → confidence validation.

`06–07` **Team Strength evaluation**  
Strength-gap performance → confidence validation.

`08–09` **Match Result evaluation**  
Coverage + conditional accuracy → confidence validation.

`10` **Version benchmarking**  
Compare BTTS, Strength and Result across engine/model versions.

`11` **Executive reporting**  
Monthly KPIs across all three cards.

`12` **Decision science**  
Evidence-aware GOOD / WATCH / POOR league decisions.

`13` **Cross-card fulfilment**  
Confidence fulfilment, simultaneous-card outcomes and rolling trends.

`14` **Advanced league reliability**  
All-time, card-percentile, recent and away-result reliability.
